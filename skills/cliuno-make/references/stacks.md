# What `make:resource <Name>` produces, per stack

Generated by `cliuno make:resource Product --fields name:string,price:number,inStock:boolean`
in each template (timestamps masked). Every backend resource is auth-guarded, owned by the
authenticated user, exposes list / get / create / update / delete under `/api/v1/<kebab-plural>`
(plus `/current-user` where the template's todo has it), and answers with
`{status, message, data: { <camel> | <camelPlural> }}`. Frontends get an API client plus a
list page (create + delete) and a detail page using the template's own UI kit.

Single-file kinds marked with → delegate to the framework's CLI when its binary is on PATH and
fall back to a CLIuno stub otherwise (`component` on web frontends delegates to the shadcn-style
`add` command).
